# Tokemoji Battles — user-approved addition

Three shareable visual barometers: GREED vs FEAR, GOOD vs EVIL, LOVE vs HATE.
Main assistant implements personally; no delegation. Preserve v1 visual identity.

Design: full-width comic face-offs, enormous opposing canonical characters, animated tug-of-war meter, contrasting team colors, prominent VS, short readable verdict, dated source label. Desktop cards stack on scroll; mobile flows normally. Pointer tracking on characters, scroll-driven entry and rotation, reduced-motion fallback.

Data honesty: these are news-derived Guru emotion comparisons, NOT sample Pump.fun token price comparisons. Inspect actual feed/schema before implementation. Normalize documented comparable scores only when valid data exists; show source window and timestamp. No invented live percentages, viewers, votes, or engagement. Missing data shows unavailable; any interactive illustrative mode must be visibly DEMO.

Sharing: per-pair URL anchor + native Web Share with clipboard fallback; do not claim social posts or automated sharing. Offer downloadable share card only if actually rendered and tested. Headlines in hero are separately labeled fictional WHAT IF scenarios and must not contaminate real barometer scores.

Acceptance: each pair is immediately recognizable; visible motion actually exercised in browser; touch and keyboard access; no horizontal overflow; real-data and missing-data states checked; share/copy controls exercised without posting externally.
